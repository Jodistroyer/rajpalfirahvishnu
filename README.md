## SEO & AI discoverability

This site is built for **Google Search**, **Google Images**, and **AI assistants** (ChatGPT, Perplexity, Claude, etc.).

### Machine-readable indexes

| File | Purpose |
|---|---|
| [`llms.txt`](llms.txt) | English index for AI crawlers — lawyers, FAQs, Media Room, all 74 clippings + 45 press items |
| [`ms/llms.txt`](ms/llms.txt) | Bahasa Malaysia index |
| [`robots.txt`](robots.txt) | Crawl rules; references both sitemaps and llms.txt |
| [`sitemap.xml`](sitemap.xml) | Page URLs (EN + MS, media anchors, legal pages) |
| [`sitemap-images.xml`](sitemap-images.xml) | All newspaper clippings + press thumbnails with titles and captions |

### On-page SEO (every major page)

- `<title>`, meta description, keywords, canonical, `hreflang` (EN / MS / x-default)
- Open Graph and Twitter Card tags
- `robots: index, follow, max-image-preview:large`
- JSON-LD structured data (`LegalService`, `Person`, `FAQPage`, `CollectionPage`, `ImageGallery`, `NewsArticle`)

### Media Room (Google Images + AI)

The Media Room is the highest-value SEO asset:

- **74 newspaper clippings** — full scans at `assets/media/newspaper-clippings/`
- **45 press items** — links + thumbnails at `assets/media/press/`
- **Static crawl fallbacks** — `<noscript>` HTML with real `<img src="...">` tags, alt text, and captions (generated by script; not JS-only)
- **Static JSON-LD** — full `ImageGallery` + press `CollectionPage` injected in `/media/` and `/ms/media/` heads
- **Image sitemap** — every clipping listed with `image:title` and `image:caption`
- **Googlebot-Image** — explicitly allowed in `robots.txt`

### Runtime SEO modules

| Module | Role |
|---|---|
| [`js/clippings-seo.js`](js/clippings-seo.js) | Alt/title text + JSON-LD for clippings (skipped if static JSON-LD present) |
| [`js/press-seo.js`](js/press-seo.js) | Alt/title text + JSON-LD for press grid |
| [`js/clippings.js`](js/clippings.js) | Gallery UI; SEO meta applied per card |
| [`js/press.js`](js/press.js) | Press grid UI; SEO meta applied per card |

## Build & regenerate scripts

Requires **Node.js 18+** (ES modules). No `npm install` needed.

### Before every deploy

1. Set your real domain in **two places**:
   - [`data/people.json`](data/people.json) → `"siteOrigin": "https://yourdomain.com"`
   - [`scripts/generate-sitemaps.mjs`](scripts/generate-sitemaps.mjs) → `SITE_ORIGIN`

2. Regenerate all SEO outputs:

```bash
node scripts/generate-people-seo.mjs
node scripts/generate-sitemaps.mjs
node scripts/generate-people-seo.mjs --llms-only
```

### Script reference

| Command | What it generates |
|---|---|
| `node scripts/generate-people-seo.mjs` | Profile page meta, JSON-LD, press sections, llms.txt |
| `node scripts/generate-people-seo.mjs --llms-only` | llms.txt + ms/llms.txt only (fast refresh) |
| `node scripts/generate-sitemaps.mjs` | sitemap.xml, sitemap-images.xml, press/clippings noscript, static Media Room JSON-LD |
| `node scripts/generate-ms-locale.mjs` | press-data-ms.js, clippings-data-ms.js (after editing English source) |
| `node scripts/generate-rights-log.mjs` | media/rights-log.html (image attribution log) |
| `node scripts/generate-clipping-thumbs.py` | JPEG thumbs in `assets/media/newspaper-clippings/thumbs/` |

### Adding new content

**New lawyer** — edit `data/people.json`, add photo under `assets/people/`, then run `generate-people-seo.mjs`.

**New press item** — add entry to `js/press-data.js`, add thumbnail to `assets/media/press/`, then run `generate-sitemaps.mjs` and `generate-ms-locale.mjs`.

**New newspaper clipping** — add image to `assets/media/newspaper-clippings/`, add entry to `js/clippings-data.js`, generate thumb, then run `generate-sitemaps.mjs` and `generate-ms-locale.mjs`.

## Deploy checklist (Search Console)

After going live with the real domain:

- [ ] Replace `[yourdomain]` everywhere and re-run both generate scripts
- [ ] Submit `https://yourdomain/sitemap.xml` in Google Search Console
- [ ] Submit `https://yourdomain/sitemap-images.xml` in Google Search Console
- [ ] Request indexing for `/media/` and `/media/#clippings`
- [ ] Verify `https://yourdomain/llms.txt` is publicly accessible
- [ ] Verify `https://yourdomain/robots.txt` lists both sitemaps
- [ ] Test a clipping URL directly in the browser (full PNG/JPG should load)

### Google Images expectations

| Asset type | Indexing likelihood |
|---|---|
| Lawyer headshots (`assets/people/`) | High — original content |
| Press thumbnails (`assets/media/press/`) | Moderate — your hosted previews |
| Newspaper clippings (`assets/media/newspaper-clippings/`) | Moderate — third-party archive scans; technically discoverable, not guaranteed |

Indexing typically takes **weeks** for new domains. The technical setup is correct; visibility depends on crawl frequency and Google's indexing choices.

## Maintainers

When updating SEO-related content, always regenerate — never hand-edit generated files:

- `llms.txt`, `ms/llms.txt`
- `sitemap.xml`, `sitemap-images.xml`
- Press/clippings `<noscript>` blocks inside HTML (marked `<!-- press-noscript:start -->`, `<!-- clippings-noscript:start -->`, `<!-- media-jsonld:start -->`)

**Regenerate command (full SEO refresh):**

```bash
node scripts/generate-people-seo.mjs && node scripts/generate-sitemaps.mjs && node scripts/generate-people-seo.mjs --llms-only
```
